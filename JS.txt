----> Variable Name / Variable in javascript : 
   
      it is a container which holds the type of data 

      a name which stores the data  --- variable name

          name = "uday";

 -----> Rules of writing Variable name 
  
    -- if a variable name starts with _ (underscore ) /$(dollar symbol) and characters
        we can treat the name as variable name 

      ex : _name  , n_ame , @name , $name, nam$e 

    -- if a variable name starts numbers we dont consider it as variable name |

      ex :  1name , n1ame , n_1ame , std1 , std$1 

    -- if a variable name has spaces we dont consider it as variable 
       
       ex : name_1 , na me1 , nam$ 1 

    -- javascript is a case sensitive language 
     
      ex : name , Name 

    -- javascript uses cameCase for naming convention 
     
       ex : empName ="uday";
            employeeName ="uday";

----> Variable keywords in JS

             which  is declared only once  but the values can be updated 

            {
                 // block
            }

       ex : 
               let name ="uday";
                name="sampath";
                console.log(name);


            let name ="uday";
             let name="sampath";
              console.log(name);   // name has been decalred error

    2. const  -- it is also a block scope variable keyword 
                  which is declared only once and also cannot be updated

            ex : 
                   use the same code but change the keyword 

    3. var    --  it is a global scope variable keyword 
                   which can be redecalred and updated
