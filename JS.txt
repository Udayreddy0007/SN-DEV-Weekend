----> Operators :  to perform  calculations in programming 
                       we use operators

    --  operands   : the two variable before and after the operators 
        
        ex :  a + b ;  -- a , b are operands  + is operator 


    -- operator : the symbol btw the operands 
      
        
 ---> In javascripts we have 4  types operators 

   
   1 . Arithematic operators :   to perform addition , substraction , division and modulo 

      (+ , -, / ,% , *)


    2 . Compound Assignment operator : it's combination of assignment and arithematic operators 
        
        (+= , -= , *= ,/= ,%= , **(ternory operator))

        ex : a = 10 ;
               a+=5 ; -- a=+ -- a +5 --10+5 -- 15 -- 15
               console.log(a);  ---

    3 .  Comparisions operators : To compare two operands  
      
          (== , === , <=,>=,<,> ,!=)


         --> == : is used for comparing the two values it'll give you a Boolean output  

        ---> ===  : is used for exact comparision it'll check both values datatypes even though the 
                      values are same 

              ex : 
                   a=10;
                   b="10";
                  console.log(a===b); // false

    4. Logical Operators : To check the conditions we will be using them 
     
         -- &&(AND) : it check both conditions if both conditions are true then only we get output as true 

         -- ||(OR) : at least one condition should be true then only we get output as true
          
         -- !(NOT) : if a condition is true it gives output false 

    5. Increment and decrement : 
        
       --> ++(increment) :  Incrementing the original value by +1
          
          ex : a=10 ;
               a++; // a + 1 = 10 + 1 = 11

       --> --(decrement) : Decrementing the original value by -1
      
         ex : a=10 ;
               a--; // a - 1 = 10 - 1 = 9

 ---> Conditional statements :   The block will be exceuted when the condition is true 
  
     
     1. if block (true block): when the condition is true then only the block will be executed 
        

        syntax : 
             
                 if(conditions) 
                 {
                       // true statement
                       
                 }


     2. Nested if block : we write multiple true blocks 
        
        syntax : 
              
                    if(cond1){
                       
                        // statement1
                    }
                    if(cond2){
                      //statement2
                    }
                    if(cond3){
                      //statement3
                    }

     3. if else(true and false):  when the condition is true then only the block true will be executed otherwise

            default block is exceuted
             
             syntax :

                 if(conditions) 
                 {
                       // true statement
                       
                 }

                 else{
                          // default block (false block)
                 }


                     

     4. else if : we can write the condition for false block as well
         
         syntax : 
            
                 if(cond1){
                   
                      //stmt1 
                 }
                 else if(cond2){
                  // stmt2
                 }
                 else{
                   
                     // default statement
                 }

     5. nested else if :  we write multiple false block conditions 
      
         
           syntax : 
               
                 if(cond1){

                     //stmt1 
                 }
                 else if(cond2){

                  //stmt2
                 }
                 else if(cond3){

                  //stmt3
                 }
                 else{

                  //default statement 

                 }



----> Looping control statements / iterative statements : 

   -- a loop will be iterate as long as condition is true      


     1 . for loop  - the loop iterates until the stopping condition is true 


           syntax : 

                 Note : i is iterative variable
                
                var i = 0;

                for(var i=0; i<=10; i++){

                  // statement;
                }

                i = 0 ; loop starts here  intial value
                i<=10; stopping condition 
                i++  ; Increment




     2. while loop :  the  condition is checked then the loop is executed 
       
        syntax : 
          
              var  i = 0;
              
              while(i<=10){

                //statement

                i++;
              }


     3. do while loop : the loop is excecuted at least once and condition is checked at the last 


          Syntax : 
 
             var i=0;
               do{
                // statement ;
                i++;
               }while(i<=10);
